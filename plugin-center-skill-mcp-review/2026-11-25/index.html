运行时清单项 包含的具体技能/工具 评测集覆盖状态 已覆盖的具体 Case 实例

市场情报 (卖家精灵/Sorftime/SIF) sellersprite-mcp、sorftime-mcp、sif-mcp 等 gateway 服务 间接覆盖 main-agent-market-intel-refuse-001 验证了市场数据查询的拒绝边界，但未限定具体 server 路径。
Builtin 业务技能 19 个 builtin 技能 (包括 violation-detection 等) 完全空白 main-agent-skills.yaml (glob) 跑的是 1.0 的 shop-fetcher / campaign-fetcher 等旧脚本，未覆盖这 19 个 builtin。
dev 新增技能/MCP html-to-pdf、luckee-plugin-smoke、display-files、write-validated-json 完全空白 没有针对这 4 个插件自带项目的任何 initialize 或 tools/list 校验。

汇总覆盖

  • 9 个 dev 官方插件 MCP：模板 query 可触达 luckee_main_agent、lingxing、amazon_ads_main、amazon-product、sellersprite-mcp、sorftime-mcp、sif-mcp，以及报告/文件链路 display-files、write-validated-json。
  • Builtin / 插件 Skill：可触达 html-to-pdf、amazon-review-scraper、amazon-product、listing-optimization-orchestrator、selection-* 等；但不能替代对每个 slug 的独立加载校验。
  • 仍不覆盖：luckee-plugin-smoke 插件自检、19 个 Builtin 的逐项 SKILL.md 存在性、initialize/tools/list 契约、错 Token 拒绝、用户自定义 MCP 重名覆盖与 A/B 用户技能隔离。
