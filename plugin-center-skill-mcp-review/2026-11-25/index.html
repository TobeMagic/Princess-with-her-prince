汇总覆盖

  • 9 个 dev 官方插件 MCP：模板 query 可触达 luckee_main_agent、lingxing、amazon_ads_main、amazon-product、sellersprite-mcp、sorftime-mcp、sif-mcp，以及报告/文件链路 display-files、write-validated-json。
  • Builtin / 插件 Skill：可触达 html-to-pdf、amazon-review-scraper、amazon-product、listing-optimization-orchestrator、selection-* 等；但不能替代对每个 slug 的独立加载校验。
  • 仍不覆盖：luckee-plugin-smoke 插件自检、19 个 Builtin 的逐项 SKILL.md 存在性、initialize/tools/list 契约、错 Token 拒绝、用户自定义 MCP 重名覆盖与 A/B 用户技能隔离。
